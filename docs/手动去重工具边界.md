# 手动去重工具边界（对标自竞争检索）

YICOPY 自竞争检索允许粘贴「已投放」与「待投放」两组关键词，投放前过滤重复，避免同账户互相竞价（CPC 上涨）。我们补同款**纯本地规则函数**，页面交互随后接入。

## 匹配口径（与互搏检测一致，对齐 Amazon 规则）

对每个待投放词 `p` 与每个已投放词 `e`（都先 canon：小写、去空格与标点）：

1. **exact 冲突**：`canon(p) === canon(e)` ——完全相同（close variants 的单复数/拼写变体不在本地规则内，标注「词形变体未检测」）。
2. **phrase 冲突**：`e` 是 `p` 的连续子串（或反向）——待投放包含已投放且顺序一致。
3. **broad 冲突**：`p` 的词袋（分词后集合）包含 `e` 的词袋——顺序无关。

**优先级**：exact > phrase > broad（一个词对只报最高级冲突），与互搏检测的口径说明一致。

## 输出

`dedupKeywords(existing[], planned[])` 返回 `{ conflicts: [{ planned, existing, level }], clean: string[] }`：

- `conflicts` 按 level（exact→phrase→broad）与 planned 词排序；同一 planned 取**最长/最具体**的 existing 为代表，不重复列。
- `clean` = 无任何冲突的待投放词（保留原输入顺序）。
- 输入空串/重复输入先按 canon 去重。

## 边界

- 本地字符串规则，**不做词形还原**（lamp/lamps 不算同词，标注由 UI 提示）；语义扩展（广泛匹配的同义词触发）无法本地检测，边界同互搏检测。
- 不上传任何数据；纯函数可测试；两套前端共用。
