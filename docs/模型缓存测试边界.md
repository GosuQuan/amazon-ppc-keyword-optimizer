# 模型缓存测试边界

本轮只减少完全相同请求的重复上游调用。先定边界，再用模拟网络验证，不调用真实模型。

- 仅缓存 HTTP 成功且可解析的 JSON 对象。错误、连接失败和非 JSON 响应不缓存，下一次仍访问上游。
- 缓存键包含服务商主机名、路径、模型、温度、max_tokens、消息和 thinking 设置。不含 API 密钥、URL 参数或完整原始地址。
- 缓存只存在当前进程内存，默认 10 分钟，最多 100 条。`AI_CACHE_SECONDS=0` 关闭。服务重启后清空。
- 命中时不访问网络，不新增账本记录，响应头为 `X-PPC-Cache: hit`。因此 token 汇总不会把一次上游调用算两次。
- 未命中的成功响应头为 `miss`。账本仍只记录真正发出的上游调用。
- 自定义接口缺少独立密钥时，仍先返回 400，不查缓存、不访问网络。
- 当前分支是单人本机使用。缓存没有账户隔离，整合远程登录体系前不能部署到公网。
- `cache_hits` 只统计本次进程启动后的命中次数。它不是已节省金额；费率未知时费用仍为未知。
