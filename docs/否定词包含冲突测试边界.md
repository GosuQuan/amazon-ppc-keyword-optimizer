# 否定词包含冲突测试边界

- 否定词去掉空格和标点后，如果长度至少 4，并且被一条优质搜索词包含，或反过来包含一条优质搜索词，就标成“与优质数据冲突，不建议否定”。
- 完全相同的优质词仍按原来的冲突规则处理。
- 长度短于 4 的碎片不因为包含关系升级成冲突，仍是“需人工复核”。
- 这只改变模型否定建议的复核标记，不自动批准，也不写入广告后台。

## 数据依据

ASIN B089K9L3VY 的竞品关键词表有 1685 行。其中 123 行包含 omooton、samsung、google、nexus 或 c4。全表有 716 行与使用次数最高的前 40 个词存在互相包含。真实模型曾建议否定 cell phone，而 cell phone stand 是高频相关词。只做全词相等的检查会漏掉这种误伤。
