# 关闭推理测试边界

- 请求体里的 `thinking` 只有布尔值生效。`false` 时上游载荷是 `{"type":"disabled"}`，`true` 时是 `enabled`。
- 不传 `thinking` 时，除了智谱 GLM-5.3 的原有默认开启，不额外加入该字段。
- 字符串、数字不会被当成关闭或开启。
- 关键词扩词请求固定发送 `thinking: false`。2026-11-03 用同一份 40 词提示重跑真实扩词任务：HTTP 200、缓存未命中，**推理 token 为 0**，输出 477，输入 337，合计 **814**；返回 12 个扩词与 5 个否定候选，JSON 可解析。对照未关闭推理的同一提示为 8065 token（其中推理 7177），降幅约 89.9%。两次都是一次独立生成，不能把差额写成稳定节省或已节省广告费。
- 同一份真实响应随后导入页面做端到端验证：12 条 AI 扩词、5 条否定预判、12 条新词候选全部渲染；由于测试报表里没有这些词，界面统一显示「未出现 / 待验证」，说明 `reportRows`、`reportOrders`、`advice` 三个派生字段在真实响应下正确生成。
