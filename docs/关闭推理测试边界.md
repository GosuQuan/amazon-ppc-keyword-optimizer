# 关闭推理测试边界

- 请求体里的 `thinking` 只有布尔值生效。`false` 时上游载荷是 `{"type":"disabled"}`，`true` 时是 `enabled`。
- 不传 `thinking` 时，除了智谱 GLM-5.3 的原有默认开启，不额外加入该字段。
- 字符串、数字不会被当成关闭或开启。
- 关键词扩词请求固定发送 `thinking: false`。2026-11-01 用同一份 40 词提示重跑：输入仍是 337 token，推理 token 为 0，输出 512，合计 849。上一次未关闭推理时合计 8065，其中推理 7177。两次都返回了 12 个扩词，新结果仍含 samsung。这是模型 token 减少，不是广告花费节省，也还没有人民币账单。
