# 关闭推理测试边界

- 请求体里的 `thinking` 只有布尔值生效。`false` 时上游载荷是 `{"type":"disabled"}`，`true` 时是 `enabled`。
- 不传 `thinking` 时，除了智谱 GLM-5.3 的原有默认开启，不额外加入该字段。
- 字符串、数字不会被当成关闭或开启。
- 关键词扩词请求固定发送 `thinking: false`。2026-11-01 用同一密钥对“只回复 OK”做了一次真实调用，服务商返回推理 token 0、合计 19。关键词扩词任务本身还没有用关闭推理重跑，不能把和上次 8065 token 的差额当成已节省费用。
