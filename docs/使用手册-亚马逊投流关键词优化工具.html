亚马逊投流关键词优化工具 · 使用手册

版本 v1.0-P0 · 2026-10-29 · 适用平台：Windows（浏览器打开，无需安装）

一句话定位：把亚马逊「搜索词报告」变成一份可直接执行的优化清单——调价、否定、收割、新词，条条带理由。

0 · 这是一款什么工具

面向中国跨境亚马逊卖家的本地广告优化工具：上传商品推广「搜索词报告」CSV 后，自动完成关键词分级、调价测算、否定词识别、优质搜索词收割、词根挖掘与互搏检测，并输出可直接在广告后台应用的清单。

  • 规则引擎 + AI 双引擎：规则层全部可解释（每条建议附触发数据）；AI 层做语义扩词、意图聚类与否定预判。
  • 数据不出本机：纯前端计算，报表不上传任何服务器；AI 仅接收关键词文本。
  • 免费起步：规则功能无限制使用，无账号、无订阅。

1 · 快速开始（30 秒上手）

  1. 1双击 启动工具.bat（或直接双击 亚马逊投流关键词优化工具.html）——浏览器自动打开工具页；
  2. 2没有报表？点 ▶ 载入示例数据（Demo） 体验完整流程；有报表就把卖家后台导出的 CSV 拖进虚线框；
  3. 3在「② 优化参数」确认目标 ACOS（默认 25%）→ 点「↻ 按新参数重新计算」→ 逐页查看结果 → 到「导出中心」下载清单。
报表位置：卖家平台 → 广告 → 报表 → 商品推广 → 搜索词报告，建议导出近 30–60 天。支持多文件合并（多店铺/多站点分别导出后一起拖入）。

工程/验收提示：页面提供 🧪 自检（回归测试集） 按钮，内置 31 条断言（解析、7 级分级、6 类调价动作、否定/收割/互搏边界），点击即可验证当前引擎状态。

5 · 规则说明（引擎如何思考）

5.1 关键词/搜索词七级分级

级别判定条件（有订单）无订单词的判定默认策略
优秀ACOS ≤ 0.6×目标—提价抢量（≤上限），收割其搜索词
良好0.6×目标 < ACOS ≤ 目标小幅提价或维持
偏高目标 < ACOS ≤ 1.5×目标小幅降价至盈利出价上限
亏损ACOS > 1.5×目标降价；无法盈利则暂停
无效点击 ≥ 阈值 且 花费 ≥ 2×客单价×目标ACOS，或 ≥ 2×允许花费广泛/词组/自动 → 降价+否定；精准 → 暂停
观察点击 < 最少判断点击数 且未超允许花费不动，继续积累数据
潜力其余无订单情形不动，再给曝光机会

允许花费 = 点击 × 预期转化率 × 目标ACOS × 客单价（例：10 次点击 × 10% × 25% × $25 = $6.25）

5.2 调价模型

盈利出价上限 = 目标ACOS × 客单价 × 关键词转化率。优秀词提价但不越过上限；偏高/亏损词降价至上限；上限低于最低出价时直接建议暂停。

出价说明：搜索词报表不含真实出价，工具以「最高历史 CPC × 1.15」估算当前出价并在界面标注（估）。P0 后续版本支持导入关键词报表/批量表获取真实出价（见路线图）。

5.3 否定、收割与互搏

  • 精准否定：无效搜索词（点击≥阈值且超支）在广泛/词组/自动投放中阻断；精准投放的无效词走「暂停」而非否定。
  • 词组否定：亏损词根（≥3 个无效词共享、零销售额、花费达 3 单目标广告费）→ 词组级止损；生成前自动检查影响面，命中现有优质词即不否定并提示冲突。
  • 收割：广泛/词组/自动中 ACOS 达标的搜索词 → 建议加入精准投放；已是精准词的提示核对出价。
  • 互搏：同一搜索词投在多个组 → 保留最优位置，输家位置精准否定，避免自竞价抬价。

6 · AI 功能使用指南

接入方式前置条件适用场景
本机代理（推荐）运行 python ai_proxy.py，从 http://127.0.0.1:8787/tool 打开页面本机使用，解决浏览器跨域；Key 可由启动参数传入
直连大模型 API自填 OpenAI 兼容接口地址 + API Key + 模型名接口支持浏览器直连时（如部分开放平台）
关闭无只用规则挖掘，离线可用
  1. 先完成规则分析（导入报表或载入示例）；
  2. 在「③ AI 模型挖掘」选择接入方式，填写产品/品类信息（越具体扩词越准）；
  3. 点「✦ 开始 AI 挖掘」→ 得到三类结果：AI 扩词（长尾/场景/人群/规格，含查重）、意图聚类（广告组结构建议）、否定预判（与规则交叉验证标注置信度）；
  4. AI 扩词并入「新词候选」与「新增关键词清单」导出；AI 否定预判中与规则一致的标为高置信。
隐私边界：AI 只接收关键词文本与品类描述，不发送花费、销售额、订单等经营数据；API Key 默认不落盘。

7 · 常见问题 FAQ

问题解答
上传后提示「无法识别表头」？确认导出的是「搜索词报告」且为 CSV/TXT；若用 Excel 另存过，请选 CSV UTF-8。工具兼容中英/双语表头与 GBK 编码。
建议出价能直接用吗？估算值仅供方向参考（界面标「估」）。建议先在 1–2 个广告组试运行，验证 5–7 天后再扩大。
为什么有些 0 订单词没有否定？点击未达「最少判断点击数」（默认 8）的词进「观察」，数据不足不下结论，避免误杀潜力词。
词组否定会不会误伤好词？引擎在生成前检查影响面：该词根若命中任何优秀/良好搜索词即不出否定，改为冲突提示。
ACOS 多少算健康？取决于毛利率。工具默认 25%，请按「毛利率 - 其他费用占比」设定，宁可保守。
多店铺/多站点怎么用？分别导出报表后一起拖入即可合并分析；注意币种不同时不要混算客单价。
数据会被上传吗？不会。规则功能全部在浏览器本地计算；AI 模式仅发送关键词文本。
自检按钮是做什么的？内置 31 条回归断言（R-T0 测试集），点击验证当前引擎行为与测试边界一致，全绿为正常。

8 · 边界与免责

  • 本工具为决策辅助：所有建议基于你上传报表的统计规律，应用前须人工复核；对直接应用建议造成的广告损失不承担责任。
  • 报表为聚合期数据（无小时级/分钟级粒度），不做分时调价建议；出价为估算值（真实出价接入在路线图中）。
  • AI 生成内容可能不准确，仅供关键词研究参考；AI 否定预判与规则冲突时以规则为准。
  • 请遵守亚马逊广告政策与当地法律法规；工具本身不采集、不上传你的任何经营数据。
