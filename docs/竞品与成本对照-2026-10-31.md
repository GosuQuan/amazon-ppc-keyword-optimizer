# 竞品与成本对照（2026-10-31）

调研日期：2026-10-31（Asia/Shanghai）。方法：仅公开网页 web_search / web_fetch，无浏览器自动化、无登录、无购买。本文是本轮研究快照，供主任务每 30 分钟迭代总结引用；不表示已运行持续监控。功能“已核实”仅指官方公开说明可读，不代表实际账号实测或收益验证。

## 1. 本轮结论

1. YICOPY 的免费工具、Visual、Ultra 是不同产品。¥9.90/月查询包不能当作完整广告经营方案的价格；Ultra 官网显示 ¥3,000/月起，具体交付额度与附加费尚未知。
2. 对标优先级应落在“数据证据→动作解释→审核→可核验导出→复盘”。YICOPY Ultra 已公开三份 SP 报表到方案和批量草稿的路径；sellerboard 也公开人工批准模式，不能声称人工审核是我们的独家能力。
3. 当前仓库已不只是 CSV 分析器：有 Bulk 真实出价/ID、审核门禁、TSV 草稿；本轮读取的代码还包含推广商品和广告位的独立事实表。差距是数据覆盖、持续同步、真实执行回执、成熟的预算/分时策略和商品经营数据，不应一概写为“尚无三报表”。
4. 官方营销页面中的神经网络预测、ROAS/订单提升或竞品优劣描述不是因果证据。没有同口径试验，不计算节省广告费或回本周期。

## 5. 成本口径与公式

统一月周期，统一比较范围（账号数、站点、ASIN、报表次数、审核动作量、外部关键词量），分别保留 USD/CNY 原始账单。不同币种必须记录换算日期和汇率后才能形成同币种总额；报价未知填 null/未知，不能填 0。

### 5.1 五类成本单独记账

| 项目 | 公式 / 字段 | 边界 |
|---|---|---|
| 数据成本 D | D = Σ(数据源固定费 + max(0, 调用量−包含额度)×超额单价)；整包计费则按实际购买包数 | 如果数据已含在订阅里，此处记 0 增量并写“包含于S”，不得再次计费；人工导出时间记 H |
| 模型成本 M | M = Σ模型[(未缓存输入token×输入单价 + 缓存输入token×缓存单价 + 输出token×输出单价)/1,000,000] + 实际额外工具调用费 | 单价单位需统一每百万token；记录重试/失败调用真实账单；算力点数不等于token；外部 Agent 订阅已含部分不重复计算 |
| 人工成本 H | H = Σ角色(采集清洗小时 + 审核小时 + 上传处理小时 + 复盘小时)×该角色全成本时薪 | 自己操作也有时间成本；用工时实测，不能假设使用 AI 后归零 |
| 订阅成本 S | S = 固定平台费 + 实际席位/账号增购 + 按合同计提的管理费 + 一次性费用摊销 | 年付折月与当月现金支付分开；管理费只在条款证实后按对应广告花费基数计算，不能默认 2% |
| 广告浪费 W | W_candidate = Σ满足明确诊断条件的搜索词花费；另列观测周期、订单归因截止、规则版本 | 这是广告支出的候选问题部分，不是软件费，更不是已经节省的费用。无单花费可能有延迟转化或品牌作用 |

工具运营成本 C_tool = D + M + H + S + I，其中 I 为单列基础设施/维护成本（若忽略须注明）。用于现金流预算时可列 C_cash = 实际工具现金支出 + 广告总花费 A；人工机会成本另列。W_candidate 是 A 的一个诊断子集，不能再把 A + W_candidate 相加。

实际增益比较需要同口径对照：净贡献变化 = 广告后贡献利润变化 − 新增工具运营成本。若计算利润时已扣广告支出，不能再扣 W 或把“节省广告费”重复加为收益。广告后贡献利润需要销售、商品成本、平台费用、履约、退货等数据；只有广告报表时不能声称净利润变化。

### 5.2 透明的预算演算（纯假设，非厂商报价、非收益预测）

假设月处理20批，每批20,000未缓存输入token、3,000输出token；假设价格分别为人民币2元/百万输入、8元/百万输出，则 M = 20×(20000×2+3000×8)/1,000,000 = ¥1.28。若每批审核15分钟、假设人工全成本 ¥100/小时，则 H = 20×0.25×100 = ¥500。

仅这两个假设项目合计 ¥501.28，尚未包含 D、S、I，更不是完整方案报价。这说明必须测量人工审核时间，而不是只比模型 token 费。该示例不表示实际模型费率或实际用户效率。

已验证的数据增购示例：若合同适用 Perpetua 25词/$50月的额外词包，购买2包为 $100/月数据增量；基础平台费仍未知。若已有套餐包含对应额度，须先扣除包含部分，不应默认每个用户都额外付此费。

## 6. 建议的三个小迭代

以下为待排期建议，不是本研究分支已完成实现；每个以可复核产物验收，可分成 30 分钟工作切片，不承诺整项30分钟完成。

1. **数据证据卡与跨报表一致性摘要。** 基于现有三类事实表，为每份报告展示来源、周期、归因窗口、ASIN/币种核验状态与计入口径；明确未计入主指标。验收：同一广告花费不会因三表相加翻倍；周期或上下文不一致能解释并阻断相应执行。价值：贴近 YICOPY 的三报表工作流，同时保留证据边界。
2. **导出资格清单与模板校验记录。** 将真实 Bid、实体 IDs、审核人/时间、阻断原因、模板版本、导出摘要集中呈现；提供上传结果人工登记字段，保持草稿标签。验收：缺 ID/真实 Bid 的已批准动作仍不可导出；导出不自动变为已执行；没有真实上传回执不显示“Amazon已接受”。价值：缩短审核找错时间，并建立可追溯闭环。
3. **每轮成本与复盘小账本。** 记录导入批数、审核分钟、模型token/提供商/费率日期、数据与订阅实际账单；五类成本独立显示。复盘同时记录周期、促销/库存变化和归因成熟度。验收：未知价格显示未知；未调用模型时模型调用费为0但人工仍保留；候选浪费不计作已节省金额。价值：用实测工具成本和工作量决定是否值得引入外部数据/订阅。
