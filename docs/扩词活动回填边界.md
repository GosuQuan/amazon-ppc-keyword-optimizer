# AI 扩词目标活动回填边界

对标 YICOPY「自动关联广告活动，批量落地」：我们的 AI 扩词与组合新词导出时广告活动 / 组为空，需要人工对齐。本功能用**本报表内的证据**自动建议目标活动，不引入任何外部数据。

## 规则（先写边界）

对组合与 AI 来源的新词候选 `word`：

1. 在本次搜索词报告的所有行里，找「`word` 是该行搜索词的子串（或反之）」的行——即该词与本店铺已投放的搜索词共享词根。
2. 在这些行里，只考虑**有订单（orders > 0）**的行，取订单数最高的一行，把它的 `camp` / `adg` 作为建议目标。
3. 找不到有订单的匹配行 → camp / adg 留空，不猜。
4. 命中时在说明里追加「按词根匹配 <camp>/<adg>，需人工确认」——这是启发式关联，不等于该词适合放进那个活动。

收割来源不参与（它们本来就直接来自实际投放行）。

## 边界

- 子串匹配是启发式：「desk trip」匹配「desk trip organizer」不代表两者该放同一活动；所以必须有「需人工确认」字样，且**只填建议不自动改数**。
- 只用本报表数据，与 YICOPY 的「竞品 Listing 证据」不同源，不冒充。
- 导出 CSV 保持列结构不变；不自动创建任何 Amazon 侧对象。
