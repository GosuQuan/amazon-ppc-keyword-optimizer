01 · 问题卖家的钱，正在三种地方漏掉

亚马逊广告是跨境卖家最大的可控成本之一，但优化决策长期处在三种状态：

① 人工试错

搜索词报告动辄数千行，运营凭感觉否定、凭心情调价；行业观察显示超六成卖家因人工试错浪费预算。

② 黑箱自动化

自动化工具按 ACOS 目标机械调价，不考虑季节性与销售趋势——这正是国际头部产品收到差评的原因；且普遍要求广告 API 授权，数据上云。

③ 价格错配

托管型工具 $695/月起、企业型近万美元，中小卖家够不着；而本土工具又把「广告优化」锁在高价档位。

03 · 工程不是脚本，是经得起审计的工程项目

  • 前后端分离：FastAPI 后端承载引擎与 API，前端为独立 SPA，接口文档自动生成。
  • 测试先行：31 条 R-T0 回归断言（解析边界、七级分级、六类调价动作、否定/收割/互搏边界、脏数据防御）同时运行在 pytest 与产品内「自检」按钮上。
  • 开源可查：引擎与测试公开在 GitHub，规则透明可审计——这是与所有黑箱自动化工具的根本区别。

05 · 差异化四个「别人没有」

数据不出本机

对手全部要求广告 API 授权、数据上云；我们纯本地计算。隐私焦虑即时化解，也天然规避亚马逊 DPP 合规成本。

每条建议可解释

花了多少、允许花多少、为什么调——理由写在每一行。对标「AI 决策日志」理念，但我们从第一天就是规则透明的。

专家 Agent 内置

无需自配模型 Key：导出优秀关键词 → 数据挖掘专家 Agent 返回结构化 JSON → 一键导入合并，交叉验证标注置信度。

免费起步 + 本土价

核心规则引擎永久免费；订阅价贴着本土价格带下沿（¥199/月），以国际产品约 1/3 的价格提供同层能力。

07 · 增长零预算冷启动的五个优先动作

  1. 内容矩阵（重仓）：B站/知乎/公众号做「搜索词报表分析教程 + PPC 术语长文」——卖家精灵「大咖课堂」与顾小北模式已验证，长尾流量精准且免费。
  2. 免费工具即漏斗（重仓）：产品本身就是 lead magnet（Helium 10 免费工具、Advigator 中文 PPC 课程同款打法），「数据不出本机」是天然传播点。
  3. 私域承接：卖家群 + 知识星球训练营，把教程读者转成免费用户再转付费。
  4. 联盟分销：复制 Helium 10「25% 循环佣金」结构，让跨境博主与导航站代销。
  5. 官方目录：产品成熟后申请亚马逊 SPN 服务商网络与雨果服务市场入驻。

09 · 风险与合规

  • 可复制性：单点功能无壁垒，护城河在「规则库持续运营 + 中文卖家社群 + 本地隐私信任」。
  • 平台政策：CSV 路线不经 API、无审批风险；一旦接 Ads API/SP-API 将触发官方审批与数据保护政策（WAF、加密、渗透测试），坚持本地路线即为合规护身符。
  • AI 成本：专家 Agent 走平台内置模型能力，免费层限量防滥用，专业层放量收费覆盖边际成本。
