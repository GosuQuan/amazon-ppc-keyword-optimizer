# 工作台积分提示测试边界

- 导入报告前显示生成方案、示例方案、首次导出和个人 Flash 模型的积分。
- 数字只来自定价接口。缺字段或不是整数时显示“暂时无法读取”，不编造价格。
- 文案写明积分不是人民币，方案生成失败会退回积分。
- 提示本身不扣积分。
- 余额预览只比较当前整数积分和生成方案所需积分。不够时明确提示，够时显示扣后余额。余额不是整数时不编造。
- 示例方案、生成方案和导出草稿成功后重新读取余额。读取失败只更新提示，不撤销已经完成的方案或下载。
- 余额和价格都是整数且余额不足时，禁用对应按钮。余额或价格未知时不禁用，避免把读取失败当成余额不足。
- 已经导出过的草稿可以重复下载，不因积分不足被禁用。
