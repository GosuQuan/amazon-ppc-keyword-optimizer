# 规则否定与优质词重叠边界

规则生成的否定建议若与优秀或良好搜索词在规范化后存在不少于四个字符的包含关系，则保留建议、把类型改为“待复核勿上传”，并在理由中保留原建议类型，提示核对匹配类型和作用范围。不重叠时保留原类型。

这是一条保守的文本提示，并非亚马逊匹配规则模拟；它可能产生误报，也可能漏掉语义相关词。不同活动、广告组和时间段不能仅凭文本重叠判为冲突。工作流将带此标记的有范围否定动作保留在审核列表，但标为不可导出，审批不能绕过该限制；已有导出快照不会因本次变更重写。

自动测试覆盖亏损词根与优质搜索词重叠、不重叠，以及同一来源关键词分组内无效词与优质词重叠后工作流阻止导出。工作流按活动、广告组、来源关键词和匹配类型分组运行规则，因此跨来源关键词的文本重叠未由该规则全面检测。没有真实广告效果或上传验证。
