# 品牌与关键词建议的证据边界

当前旧版 AI 结果使用固定字符串列表 `omoton`、`samsung`、`google`、`nexus` 标记所谓竞品。现在按英文数字词边界匹配，不再匹配单词内部子串，但这仍只是样例启发式：Samsung、Google 和 Nexus 可能指兼容设备或自有品牌；字符串命中不能证明品牌归属，也不能证明该词不适合投放。用户应核对实际商品、兼容关系和投放目标。当前系统仍会根据这些标记过滤部分建议，因此可能漏掉有价值的词。

搜索词之间的字符串包含关系不等同于亚马逊匹配类型的覆盖关系。相同关键词出现在不同活动或广告组也不必然是重复投放；当前按词全局去重可能隐藏不同投放范围的候选。旧版导出 CSV 是审核清单，不能视为已验证的亚马逊批量上传模板。此前将这些处理描述为确定的“竞品”“重复购买”或广告费用节省，证据不足。

此前模型用量对比为同一保存提示词的两次调用：未显式关闭推理时合计 8065 token；关闭推理时合计 849 token。两次返回均为 12 条扩词且第二次 JSON 可解析；这不是质量等价测试，也没有对应人民币账单或广告效果。
