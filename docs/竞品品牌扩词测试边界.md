# 竞品品牌扩词测试边界

- 扩词去掉空格后如果包含 `omoton`、`samsung`、`google` 或 `nexus`，就标成“含竞品品牌，不建议作为自有新词”。
- `foldable phone stand for desk` 这种不含上述品牌的词不标。
- 不把过短的 `c4` 放进品牌表，避免把普通型号片段误判成品牌。
- 这个标记不自动删除扩词，不自动否定，也不写入广告后台。

## 数据依据

B089K9L3VY 的 1685 行竞品词里，有 123 行包含 omooton、samsung、google、nexus 或 c4。真实模型曾把 `samsung galaxy tab` 写进扩词。把竞品品牌当成自有新词会买到别人的品牌流量。
