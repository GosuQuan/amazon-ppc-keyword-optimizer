# 平台需求拆分

日期：2026-11-01。范围：把已有的广告优化闭环收成可登录的平台，并给出可解释的积分与定价。

## 拆分原则

1. 先保证账号边界，再谈页面。没有用户隔离的仪表盘只是把数据摊开。
2. 积分和人民币分开记账。积分是平台内的调用额度，不是广告费，也不是已节省金额。
3. 定价只对齐 YICOPY 公开档位的结构：低价工具包、更高工具包、企业方案起价。不把对方产品说成我们的收款项目。
4. 支付未接入前，充值必须标记为演示入账，且同一档位不能重复刷积分。
5. 每一刀都能用测试证明：扣分、退分、隔离、拒绝条件。

## 需求切片

| 编号 | 用户能做什么 | 本轮是否交付 | 验收 |
|---|---|---|---|
| P0 登录后主页 | 登录后先看到仪表盘，而不是直接掉进报表 | 是 | 登录跳转 `/dashboard.html` |
| P1 核心功能入口 | 从仪表盘进入广告工作台 | 是 | 工作台保留原审核、导出、复盘 |
| P2 积分账户 | 看到余额、档位和流水 | 是 | `/api/auth/me` 返回积分与最近流水 |
| P3 服务扣分 | 生成方案、示例、分析、首次导出、模型调用按表扣分 | 是 | 失败生成会退分；重复导出不重复扣分 |
| P4 模型差价 | 个人与企业、Flash 与其他模型价格不同 | 是 | 定价接口和调用扣分一致 |
| P5 充值 | 选择 Pro / Max / Ultra 演示入账 | 是 | 状态为 `demo_no_payment`，同档不可重复 |
| P6 真实支付 | 对接支付机构并收款 | 否 | 未做，不能显示已支付 |
| P7 广告效果 | 证明降低 ACoS 或节省广告费 | 否 | 未做投放实验 |

## 不做的事

- 不复制 YICOPY 的预测模型、Listing 生成或自动投放。
- 不把 ¥9.90、¥49.90、¥3000 写成已经收到的款项。
- 不把积分消耗换算成人民币利润。
