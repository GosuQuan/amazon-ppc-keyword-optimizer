# 竞品品牌否定测试边界

- 否定词包含 `omoton`、`samsung`、`google` 或 `nexus`，并且没有包住优质搜索词时，标成“竞品品牌，可作为否定候选”。
- 如果同一个词包住了优质搜索词，冲突标记优先，不改成品牌候选。
- 不含这些品牌、也不与优质词冲突的词，仍是“需人工复核”。
- 品牌候选不会自动批准，也不会导出到广告后台。

## 数据依据

B089K9L3VY 的词表里有 123 行竞品品牌。真实模型把 `samsung galaxy` 和 `google nexus` 放进否定建议，同时也把 `cell phone` 放进否定建议。品牌可以进入复核队列，但包住优质词的否定必须继续拦截。
