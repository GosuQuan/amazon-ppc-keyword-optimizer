# 模型缓存身份隔离

相同用户的相同请求不一定属于同一上游账号。此前缓存键没有区分接口协议、端口、查询参数或模型凭据；切换密钥后可能错误复用旧响应，导致调用与积分记录不能反映实际行为。

现在缓存键包含用户、请求参数、协议、主机、端口、路径，以及查询字符串和已配置凭据的 SHA-256 摘要。缓存仅在有明确配置的请求密钥或服务端密钥时启用；依赖动态令牌获取的调用跳过缓存。缓存依旧只在进程内，密钥和查询字符串不明文写入缓存键。摘要不应被视为加密存储方案。

测试覆盖同一凭据命中、不同凭据和不同端口未命中，以及缓存键不包含测试密钥明文；模型缓存、用量和代理相关测试共 23 项通过。未进行真实模型调用；缓存命中和上游费用仍需分别核算。
