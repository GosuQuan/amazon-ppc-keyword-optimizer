# 优质短词不被「已包含」规则误删

## 证据

YICOPY 销词引擎对 `B089K9L3VY` 的结果页把 `cell phone` 列为**第 1 高价值「必用」词**（5 个竞品使用），而它是 `cell phone stand` 的严格子串。我们的 `expansionCoveredByGood` 只判断「存在更长优质词包含它」就标记 `coveredByGood`，页面清单与导出会静默跳过——会删掉对方认定的最高价值词。

## 判据（本次实现）

若候选词**本身就是一条优质/良好搜索词**（完整匹配），说明它是一个独立的流量入口，不能仅因它是某个更长词的子串就判为「已包含」。只有「自身不是优质词、且被更长优质词包含」的碎片才标记为 `coveredByGood`。

- `word` 是 `goodTerms` 的完整成员 → `coveredByGood = false`
- `word` 不在 `goodTerms` 中、但被更长优质词包含 → `coveredByGood = true`（原行为不变）
- 长度 < 4 的极短词仍不参与判断（原行为不变）

## 边界

- 字符串包含仍不等于亚马逊匹配语义；本改动只解决「独立优质入口被误判」这一种情况，不保证覆盖判断正确。
- `exists`（与现有精准词完全相同）仍排除，`negativeContainedInGood`（否定词冲突）仍保留，两者不在本次范围。
- 没有真实 Amazon 搜索词报告来验证实际剔除率；YICOPY 导出是竞品 Listing 关键词，不是广告指标数据。
- 前端标记变化会传导到后端导出（导出依据前端传来的 `coveredByGood` 标记），因此独立优质词现在会进入导出，需人工复核是否重复投放。
