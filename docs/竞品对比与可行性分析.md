## 三、结论

1. **竞品的价值核心 = 报表挖掘 + 规则自动化 + AI 建议**。其中「数据挖掘、分级、收割、否定、调价建议、AI 扩词」全部可以离线复刻，且能做到**每条建议可解释**（对标 Xnurta 的 AI 决策日志）。
2. **竞品做不到 / 不强调的，恰是我们的差异点**：免费、数据不出本机（纯前端本地计算）、AI 与规则双引擎交叉验证、开箱即用（无 API 授权、无订阅）。
3. **一期明确不做**：自动执行（API 授权）、分时调价、排名监控、反查数据库、多渠道 —— 这些是「数据源/授权」壁垒，不是算法壁垒，列入二期路线图。
4. 与竞品最大差距是「自动执行」；一期以「一键导出可执行清单」弥补（调价/否定/新增词 4 类 CSV，人工复核后应用），二期再接 Amazon Ads API。

## 四、AI 挖掘能力设计（利用模型能力）

- **输入**：报表中的优秀关键词 + 盈利词根 + 用户填写的品类/产品信息
- **四个 AI 任务**：① 语义扩词（长尾/场景/人群/规格词）② 搜索意图聚类 → 广告组结构建议 ③ 否定词智能预判（与规则结果交叉验证）④ 关键词分组投放建议
- **接入链路**：本机模型服务（127.0.0.1:18432 自动取 token）→ 自填 API Key（智谱开放平台等）→ 均不可用时自动降级纯规则模式
- **隐私边界**：只上传关键词文本，不上传花费/销售额等经营数据
