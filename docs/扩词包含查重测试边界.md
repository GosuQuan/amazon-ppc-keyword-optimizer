# 扩词包含查重测试边界

- 模型扩出来的词，如果去掉空格后长度至少 4，并且被一条更长的优质搜索词包含，就标成“已包含在优质词中”。
- 它仍然不是“已有精准词”。精准查重只看完全相同的现有关键词。
- 更长的新长尾词即使包含某个短优质词，也不因此标成已包含。
- 短于 4 个字符的碎片不标。
- 这个标记只出现在扩词表和导出说明里，不自动否定，也不写入广告后台。

## 数据依据

B089K9L3VY 的 1685 行竞品词里，有 716 行与前 40 个高频词互相包含。只按全词相等查重，会把 `cell phone` 这种已经包含在 `cell phone stand` 里的碎片当成新词。
