# 模型用量面板验收边界

- 面板从 GET /api/ai/usage 读取记录，不触发模型请求。
- 总数为账本全历史，列表为最近50条；必须说明统计只覆盖启用记录之后的本机调用。
- 未知token和费用显示“未知”，不转换成0。已知token合计同时展示覆盖条数，不能假装完整账单。
- HTTP成功仅代表接口返回，不代表AI建议通过格式校验或投放有效。
- 请求失败明确展示错误并可刷新；不影响现有方案与审核操作。
- 外部返回内容只用textContent渲染，不插入HTML；不展示密钥、提示词或回复正文。
- 验证方式：脚本语法检查、后端边界测试、HTTP页面/脚本/API检查。浏览器布局和真实模型记账仍需单独验收。
