# 推理 token 测试边界

- 只从 `usage.completion_tokens_details.reasoning_tokens` 读取非负整数。
- 缺失、小数、字符串或布尔值保持为空，不写成 0。
- 不从输出 token 里扣掉推理 token。两边都按服务商原数保存。
- 不保存推理正文。页面说明推理 token 不是建议正文，也不等于已节省费用。
